# Арена ↔ пульт: контракт

Напрям завжди один: **пульт (192.168.1.21) → арена (192.168.1.26)**. Арена ніколи не ходить на .21, .125, .100
(`homelab/arena/nftables.conf`). Токен інтеграції: `ARENA_ALERT_TOKEN=` у `/etc/arena.env` на CT 106; на пульті його
місце визначає підпродукт `notify` (секрет, не в репо).

| Запит | Хто | Що |
|---|---|---|
| `POST /api/alert` `{"on": true\|false}` + `X-Arena-Token` | пульт при зміні стану тривоги | пауза «тривога» / відбій, оголошення на ТБ гри |
| `GET /api/alert` | будь-хто з LAN | `{"paused", "reason"}` |
| `GET /api/digest` або `/api/digest.txt` + `X-Arena-Token` (або `?token=`) | бот пульта (команда «арена», вечірній дайджест) | підсумок дня: бої, переможці, легендарки, сімейні досягнення, справи, таблиця сезону, хвилини дітей |
| `GET /api/report` або `/api/report.txt` + токен, `?back=1` = минулий тиждень | бот пульта (неділя ввечері, «арена тиждень») | звіт тижня: хвилини, бої, справи, розумні відповіді кожної дитини по днях |
| `GET /api/voice?since=N` + токен | pult@announce кожні ~5 с | черга голосу ведучого: `{n, items:[{n, at, text}]}`; `items` лише після номера N і не старіше 10 хв; текст без емодзі, готовий для TTS. Пульт сам вирішує, чи зараз можна вголос (тихі години, денний сон) |
| `GET /health` | моніторинг | `{"ok","version","players","phase","paused","tv"}` |

Сторона пульта зроблена (`mimismart-pult` PR #271, підпродукт `notify`, `domains/notify/lib/Arena.php`): `pult@announce` шле
`POST /api/alert` на початок і відбій тривоги; бот розуміє «арена» (`GET /api/digest`); о `arena.digestAt` (20:30) дайджест
в усі чати, якщо були бої. Реєстр: store `arena` (`/home/pult/arena.json`: `enabled` типово вимкнено, `alert`, `digestAt`, `host`),
секрет `/home/pult/arena-token.txt`. Увімкнення наживо: токен у файл, `arena.enabled` на сторінці налаштувань пульта.
